## 📂 Project Structure

```text
Java/
├── src/
│   ├── loops/                      # while, do-while, for, nested iterations
│   ├── pattern/                    # Star, number, and character pattern logic
│   ├── arrays/                     # 1D & 2D arrays, matrix operations
│   ├── methods/                    # Parameters, recursion, variable arguments (varargs)
│   ├── oops/                       # Classes, objects, constructors, data hiding
│   ├── inheritance/                # Class hierarchies, super keyword, method overriding
│   ├── abstract_classes/           # Base contracts, abstract methods
│   ├── interfaces/                 # Interface implementation, default/static methods
│   ├── inner_classes/              # Member, local, anonymous, and static nested classes
│   ├── static_final/               # Static variables/methods and final keyword rules
│   ├── packages/                   # Package declaration, imports, and access levels
│   ├── exception_handling/         # Try-catch-finally, checked/unchecked, custom exceptions
│   ├── multithreading/             # Thread class, Runnable, synchronization, locks
│   ├── java_lang/                  # Object class methods, String, StringBuilder, Wrapper classes
│   ├── annotations_javadoc/        # Built-in/custom annotations and documentation tags
│   ├── lambda_expressions/         # Functional interfaces, lambdas, method references
│   ├── java_io/                    # Byte & character streams, file I/O, serialization
│   ├── generics/                   # Generic classes, methods, bounded types, wildcards
│   ├── collections/                # List, Set, Map, Queue, and Iterators
│   ├── date_time_api/              # LocalDate, LocalTime, Period, Duration, DateTimeFormatter
│   ├── network_programming/        # Client-Server architecture, Socket, ServerSocket
│   ├── jdbc/                       # SQLite connection, CRUD operations, Statements
│   ├── awt/                        # Abstract Window Toolkit UI components and events
│   ├── swing/                      # Swing components, layouts, and event handling
│   └── javafx/                     # Modern GUI development, FXML, scenes, and CSS
├── .gitignore
└── README.md
```
